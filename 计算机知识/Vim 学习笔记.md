## 一、核心概念
### 1.1 Vim 是什么
Vim（Vi IMproved）是 Vi 编辑器的增强版，由 Bram Moolenaar 于 1991 年首次发布。它是一个**模式化编辑器**，与记事本、Word 等传统编辑器不同，Vim 刻意将**编辑**与**移动**分离，通过多种模式运作，让用户在键盘上就能快速完成复杂的文本操作。Vim 可以在 Unix、Linux、Windows 和 macOS 上运行，广泛应用于代码编辑、系统管理、配置文件修改等场景。

### 1.2 为什么 Vim 如此高效
Vim 的设计目的是让用户**尽可能少地移动手指**，几乎所有操作都可以通过快捷键完成。通过区分编辑和导航模式，Vim 减少了反复在方向键与鼠标之间切换的时间，让你可以“沉浸”在键盘上进行精细的文本处理，从而显著提升编辑效率。

### 1.3 模式切换——Vim 的灵魂
Vim 的独特之处在于它的**三种主要模式**，理解模式切换是掌握 Vim 的第一步：

| 模式 | 进入方式 | 作用 |
| --- | --- | --- |
| **普通模式**（Normal） | 启动默认 / 按 `Esc` | 移动光标、删除、复制、粘贴、撤销、跳转与搜索 |
| **插入模式**（Insert） | 按 `i`、`a`、`o` 等 | 输入文本，类似普通编辑器 |
| **命令行模式**（Command-line） | 按 `:` | 保存、退出、查找替换、执行外部命令 |


> **记忆口诀**：进 Vim 先别打字，`Esc` 回到普通模式再说。
>

**关键理解**：普通模式不是“闲置模式”，而是**命令模式**——你按的每一个键都是指令。`i` 不是输入字母 i，而是“进入插入模式”的命令。



## 二、基础操作
### 2.1 光标移动
**字符级移动**（用这四个键代替方向键，手指无需离开主键区）：

```plain
h    " 左移一个字符
j    " 下移一行
k    " 上移一行
l    " 右移一个字符
```

**单词级移动**：

```plain
w    " 跳到下一个单词开头
b    " 跳回上一个单词开头
e    " 跳到当前单词末尾
```

**行级移动**：

```plain
0    " 跳到行首
$    " 跳到行尾
gg   " 跳到文件开头
G    " 跳到文件末尾
:N   " 跳到第 N 行
```

**翻页**：

```plain
Ctrl+f    " 向下翻页
Ctrl+b    " 向上翻页
Ctrl+d    " 向下翻半页
Ctrl+u    " 向上翻半页
```

### 2.2 进入插入模式
在普通模式下，有多种方式进入插入模式，区别在于**光标插入的位置**：

| 命令 | 作用 |
| --- | --- |
| `i` | 在光标**前**插入 |
| `a` | 在光标**后**插入 |
| `I` | 在**行首**插入 |
| `A` | 在**行尾**插入 |
| `o` | 在**下一行**新建一行并插入 |
| `O` | 在**上一行**新建一行并插入 |


### 2.3 编辑操作
| 命令 | 作用 |
| --- | --- |
| `x` | 删除光标处字符 |
| `dd` | 删除当前行 |
| `yy` | 复制当前行 |
| `p` | 粘贴 |
| `dw` | 删除一个单词 |
| `d$` 或 `D` | 删除到行尾 |
| `cc` 或 `S` | 修改当前行（删除并进入插入模式） |
| `r` | 替换单个字符 |
| `J` | 将下一行合并到当前行 |


**组合命令**是 Vim 的精髓：`d2w` 删除两个单词，`y3j` 复制向下三行的文本。

### 2.4 撤销与重做
```plain
u           " 撤销上一步操作
Ctrl+r      " 重做被撤销的步骤
```

### 2.5 文件操作
```plain
:w          " 保存文件
:q          " 退出
:wq         " 保存并退出
:q!         " 不保存强制退出
:wq!        " 强制保存并退出（需要权限时）
```



## 三、搜索与替换
### 3.1 搜索
```plain
/关键字     " 向下搜索
?关键字     " 向上搜索
n           " 跳转到下一个搜索结果
N           " 跳转到上一个搜索结果
```

### 3.2 替换
替换命令的语法为 `:[range]s/pattern/replacement/[flags]`：

```plain
:s/old/new/g        " 替换当前行中所有 old 为 new
:%s/old/new/g       " 替换整个文件中所有 old 为 new
:%s/old/new/gc      " 替换时逐个确认
:%s/old/new/gi      " 忽略大小写
```

### 3.3 正则表达式替换
Vim 支持强大的正则表达式：

```plain
:%s/\d/X/g          " 将所有数字替换为 X
:%s/\<old\>/new/g   " 只替换完整单词 old
:%s/^/xxx/g         " 在每一行行首插入 xxx
:%s/$/xxx/g         " 在每一行行尾追加 xxx
```



## 四、可视模式
可视模式用于**选中文本**后进行操作，对应三种选择方式：

| 命令 | 模式 | 作用 |
| --- | --- | --- |
| `v` | 字符可视模式 | 按字符选择 |
| `V` | 行可视模式 | 按整行选择 |
| `Ctrl+v` | 块可视模式 | 按矩形区域选择 |


选中后可以执行 `d`（删除）、`y`（复制）、`c`（修改）、`>`（缩进）等操作。

**块可视模式的典型用途**：批量注释代码（`Ctrl+v` 选中行首 → `I` 插入 `//` → `Esc`），批量添加前缀等。



## 五、文本对象与组合命令
文本对象是 Vim 中**对“文本块”进行操作**的抽象概念，比单纯的光标移动更高效：

```plain
iw    " 当前单词（inner word）
aw    " 当前单词及周围空格（a word）
i(    " 括号内的内容
a(    " 包括括号本身
i"    " 双引号内的内容
it    " HTML/XML 标签内的内容
ip    " 当前段落
```

配合操作符使用：

```plain
ciw    " 修改当前单词（删除并进入插入模式）
di"    " 删除双引号内的内容
ya(    " 复制括号内的所有内容（包括括号）
```



## 六、寄存器
寄存器是 Vim 的“剪贴板系统”，用于存储文本：

| 寄存器 | 符号 | 作用 |
| --- | --- | --- |
| 无名寄存器 | `""` | 最近一次复制/删除的内容（默认） |
| 数字寄存器 | `"0` - `"9` | 删除历史，`"0` 是最近一次复制 |
| 短删除寄存器 | `"-` | 删除少于一行的内容 |
| 有名寄存器 | `"a` - `"z` | 用户自定义寄存器 |
| 只读寄存器 | `":`、`".`、`"%` | 最近命令、最近插入文本、当前文件名 |


**使用方式**：在命令前加 `"` 和寄存器名：

```plain
"ayy     " 将当前行复制到寄存器 a
"ap      " 从寄存器 a 粘贴
"+y      " 复制到系统剪贴板
"+p      " 从系统剪贴板粘贴
```



## 七、宏（Macro）
宏用于**录制一系列操作并重复执行**，是 Vim 中最强大的自动化工具之一。

**工作流程**：

1. `q{register}` — 开始录制，`{register}` 为 a-z 的字母
2. 执行你的操作
3. `q` — 停止录制
4. `@{register}` — 播放宏
5. `@@` — 重复播放上一次的宏
6. `N@{register}` — 播放宏 N 次

**示例**：给多行添加 `#include "..."` 格式

```plain
qa                      " 开始录制到寄存器 a
^                       " 移动到行首
i#include "<Esc>        " 插入 #include "
$                       " 移动到行尾
a"<Esc>                 " 追加 "
j                       " 移动到下一行
q                       " 停止录制
3@a                     " 对接下来 3 行重复执行
```



## 八、配置文件 .vimrc
`.vimrc` 是 Vim 的配置文件，用于自定义 Vim 的行为和外观。Unix/Linux/macOS 下位于 `~/.vimrc`，Windows 下为 `_vimrc`。

**基础配置示例**：

```plain
set number              " 显示行号
syntax on               " 开启语法高亮
set tabstop=4           " Tab 显示为 4 个空格
set shiftwidth=4        " 自动缩进为 4 个空格
set expandtab           " 将 Tab 转换为空格
set hlsearch            " 高亮搜索结果
set incsearch           " 增量搜索
set ignorecase          " 搜索忽略大小写
set smartcase           " 如果搜索包含大写字母，则区分大小写
```

**键映射**：

```plain
noremap <C-s> :w<CR>        " Ctrl+S 保存
inoremap <C-s> <Esc>:w<CR>a " 插入模式下 Ctrl+S 保存
```

配置修改后，在 Vim 中执行 `:source ~/.vimrc` 可即时生效。



## 九、插件管理
**vim-plug** 是当前最流行的 Vim 插件管理器之一，设计极简、无依赖、安装快速。

**安装 vim-plug（Unix/Linux）** ：

```bash
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

**在 .vimrc 中配置插件**：

```plain
call plug#begin('~/.vim/plugged')

Plug 'tpope/vim-sensible'       " 合理的默认设置
Plug 'preservim/nerdtree'       " 文件浏览器
Plug 'vim-airline/vim-airline'  " 状态栏增强
Plug 'tpope/vim-fugitive'       " Git 集成

call plug#end()
```

**常用命令**：

```plain
:PlugInstall    " 安装插件
:PlugUpdate     " 更新插件
:PlugClean      " 删除已移除的插件
:PlugDiff       " 查看更新变化
```

**常用插件推荐**：

| 插件 | 作用 |
| --- | --- |
| NERDTree | 文件系统浏览器 |
| vim-airline | 状态栏增强 |
| YouCompleteMe / coc.nvim | 代码自动补全 |
| ALE | 实时语法检查与自动修复 |
| Syntastic | 语法检查 |
| vim-fugitive | Git 集成 |
| nerdcommenter | 快速注释/取消注释 |


## 十、常见错误与解决方案
### 错误 1：出现 `.swp` 文件提示
**原因**：Vim 异常中断（如意外关机、关闭终端）后残留的交换文件。

**解决**：按 `A` 选择 Abort，然后删除交换文件：

```bash
rm /path/to/file.swp
```

### 错误 2：无法保存文件（权限不足）
**原因**：当前用户没有写权限。

**解决**：使用 `:w !sudo tee %` 以 sudo 权限保存，或在启动 Vim 时使用 `sudo`。

### 错误 3：配置不生效
**原因**：`.vimrc` 有语法错误，或 Vim 未正确加载。

**解决**：在 Vim 中执行 `:source ~/.vimrc` 查看报错信息，或检查 `:scriptnames` 确认加载了哪些配置。

### 错误 4：中文乱码
**解决**：在 `.vimrc` 中添加：

```plain
set encoding=utf-8
set fileencoding=utf-8
set termencoding=utf-8
```

### 错误 5：插件无法加载
**原因**：插件路径错误或插件本身有问题。

**解决**：检查 `plug#begin()` 中的路径是否正确，在 Vim 中执行 `:PlugStatus` 查看插件状态。



## 十一、高效操作技巧
### 11.1 核心心法
**尽量停留在普通模式**，把插入模式当作“临时输入”，多用移动 + 操作的组合完成编辑。用 `c{motion}` / `d{motion}` 替代先删除再插入。

### 11.2 数字前缀
Vim 中几乎所有命令都支持数字前缀：

```plain
5j      " 向下移动 5 行
3w      " 向右跳转 3 个单词
2dd     " 删除 2 行
10yy    " 复制 10 行
```

### 11.3 点命令（`.`）
`.` 命令会**重复上一次的修改操作**，是 Vim 中效率最高的命令之一。例如，删除一个单词后，移动到下一个位置按 `.` 即可重复删除。

### 11.4 分屏与标签页
```plain
:sp file       " 水平分屏打开文件
:vsp file      " 垂直分屏打开文件
Ctrl+w w       " 在窗口间循环切换
Ctrl+w h/j/k/l " 切换到左/下/上/右窗口
Ctrl+w c       " 关闭当前窗口
:tabnew        " 新建标签页
gt / gT        " 切换标签页
```

### 11.5 快速跳转
```plain
Ctrl+o         " 跳回上一个位置
Ctrl+i         " 跳回下一个位置
%              " 在匹配的括号间跳转
*              " 搜索光标下的单词（向下）
#              " 搜索光标下的单词（向上）
```

### 11.6 组合命令示例
```plain
ciw            " 修改当前单词
di"            " 删除双引号内内容
ya(            " 复制括号内所有内容
>j             " 当前行和下一行缩进
=%             " 自动缩进整个代码块
```



## 十二、学习路线与最佳实践
### 科学学习路线
```plain
阶段 1：h/j/k/l 移动 + i/a/o 插入 + :wq 保存 → 能在 Vim 中存活
阶段 2：dd/yy/p 编辑 + u/Ctrl+r 撤销重做 + / 搜索 → 基本编辑流畅
阶段 3：文本对象（iw/aw/i(）+ 组合命令（ciw/di"） → 高效编辑
阶段 4：可视模式 + 寄存器 + 宏 → 批量操作自动化
阶段 5：.vimrc 配置 + 插件管理 → 个性化工作环境
阶段 6：Vimscript 脚本 + 自定义函数 → 深度定制
```

> 推荐从 `vimtutor` 开始（终端输入 `vimtutor` 即可），它是 Vim 自带的交互式教程，30 分钟可以完成基础入门。
>

### 最佳实践
1. **保持普通模式**：把插入模式当作“临时状态”，用完立刻 `Esc` 返回。
2. **用移动 + 操作替代多次删除**：`d2w` 比按 6 次 `x` 高效得多。
3. **善用 **`.`** 命令**：重复上一次修改，减少重复劳动。
4. **用 **`ciw`** 替代 **`dw`** + **`i`：一步完成修改操作。
5. **配置 **`.vimrc`：把常用设置写进去，一次配置终身受益。
6. **不要一次性装太多插件**：先熟悉原生 Vim，再按需添加插件。
7. **用宏处理重复性任务**：录制一次，执行 N 次。
8. `u`** 是你的朋友**：误操作后立即撤销，大胆尝试。
