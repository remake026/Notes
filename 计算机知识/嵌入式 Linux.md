### 0.2 但"只学两年"= 两个真短板
| 短板 | 说明 |
| --- | --- |
| **硬件零基础**（最大短板） | 软工几乎不碰数电模电、单片机、寄存器。而嵌入式驱动岗的底层就是硬件，这是你唯一要从零补的 |
| **底层系统没碰过** | 两年软工 vs 四年科班，内核/驱动大概率没写过；项目量也有差距 |


### 0.3 你的约束：吃硕士红利 + 难度不要太大
先明确两件事：

1. **学历红利来自"卡硕士"的岗位**。成都研究所（中电科系）、芯片厂、特种电子的"嵌入式软件工程师"普遍卡硕士，天花板 2–3 万，本科进不来——这就是你的红利来源。
2. **难度别往"和科班拼硬件/内核"上走**。你是软工，硬件和内核源码是你的短板，硬刚等于拿劣势打别人的主场。

把「学历红利」和「难度」两个维度一起看：

| 方向 | 学历红利 | 难度 | 结论 |
| --- | --- | --- | --- |
| **嵌入式 Linux 系统 / 中间件开发**（系统编程 + 基础驱动） | 🟢 高（卡硕士） | 🟢 中（软工强项） | ⭐⭐⭐⭐⭐**主攻** |
| **④ 车载 / 座舱中间件** | 🟡 中（部分本科可进） | 🟢 低 | ⭐⭐⭐⭐ 保底 |
| **① Linux 驱动 / BSP** | 🟢 高 | 🔴 中高（要硬件） | ⭐⭐⭐ 学到"能写基础驱动"即可，不深挖 |
| **② 内核源码级 / 架构** | 🟢 很高 | 🔴 极高 | ⭐ 不追，只学"能讲清机制" |
| **③ 机器人 / ROS2** | 🟢 高 | 🔴 高（要机械） | 砍 |


**结论一句话**：主攻 **"嵌入式 Linux 系统开发"**（C + Linux 系统编程 + 基础驱动——软工主场、硕士卡门槛、难度适中），车载中间件当保底，内核只学机制不追源码，机器人砍掉。

> 💡 红利怎么吃：成都卡硕士的岗位考的不是"内核架构"，是 **C 扎实 + Linux 系统编程 + 能写基础驱动**。这三点全是软工一年能到顶的，而本科竞争者够不到门槛，科班硕士又不屑于做——**这就是你的甜蜜点。**
>

> 💡 简历差异化一句话：**"软件工程科班出身，Java 后端做过工程，现在把系统能力下沉到 Linux 系统层。"** —— 比"我是转行的"强一个量级。

## 一、先看结论：一年怎么分配
```plain
课题 + 研究生课程  ██████████  约 40%
动手关卡(写代码)   ████████    约 35%   ← 这 35% 决定你拿不拿得到 offer
LeetCode 刷题     ████        约 15%
杂事 / 缓冲        ██          约 10%
```

**主线一句话：C → 系统编程（重点） → 第一个驱动 → 完整驱动 → 系统实战 → 课题变现。**

| 阶段 | 月份 | 主题 | 里程碑（月底必须能…） |
| --- | --- | --- | --- |
| **打地基** | M1–M3 | C 语言精通 | 20 分钟内定位段错误；讲清`volatile` 到汇编级 |
| **系统编程** | M4–M5 | Linux 系统编程 + 网络 | 手写 shell；`epoll` 服务器四版本 |
| **入门内核** | M6–M7 | 第一个内核模块 + 内核机制 | 独立写出并加载`.ko`；讲清中断上下半部 |
| **成型** | M8 | platform + 设备树 | 独立完成一个带中断和并发控制的驱动 |
| **补硬件** | M9 | 硬件入门 + STM32（点到为止） | 逻辑分析仪抓 I2C 并解读 |
| **系统实战** | M10 | Linux 系统 / 中间件开发（软工主场） | 完成一个系统级项目 |
| **变现** | M11–M12 | 实习 / 课题项目 / 八股 | 一份可写进简历的项目 + 简历初稿 |


> 四个硬 Checkpoint：**M3 定位段错误 → M6 加载内核模块 → M8 完整驱动 → M10 系统实战项目**。任何一个卡住，先回头补上一个，不要硬往后赶。

## 二、科学学习方法（先学会怎么学）
> 方法错了，一年白干。以下 6 条是这套计划的"操作系统"，先内化。
>

### 1. 项目驱动 > 看视频（核心中的核心）
看视频产生"我会了"的错觉，只有写出来才是真的会。

**正确姿势：看一节 → 关掉视频自己复现 → 卡住再回去查。**

> 判断标准只有一条：**能脱离教程重写出来的，才叫学会。**
>

### 2. 费曼学习法：输入必须有输出
每完成一个关卡，写一篇博客（CSDN / 掘金 / 知乎）。

+ 写不出来的地方 = 没学懂的地方
+ 面试时"我有技术博客"是实打实的加分项
+ 顺便作为和导师汇报课题进展的材料

### 3. 刻意练习 + 即时反馈
不要"重复已经会的"，要**专门练最难的 20%**。反馈必须快：

| 学什么 | 反馈工具（学完立刻能验证） |
| --- | --- |
| C 内存/指针 | `gdb` core dump、`valgrind`、ASan |
| 系统调用 | `strace -f -e trace=all` 看真实调用 |
| 内核机制 | 故意在中断里`msleep()`，看内核报 "BUG: scheduling while atomic" |
| 硬件时序 | 逻辑分析仪抓波形，和时序图对照 |
| 编译链接 | `gcc -S` 看汇编、`nm`/`objdump` 看目标文件 |


### 4. 间隔重复 + 主动回忆
+ **主动回忆**：合上视频/书，先自己默写，再对照。别反复"重看"。
+ **间隔重复**：月度 Checkpoint 就是你的"艾宾浩斯复习点"。M6 复习 M2 的指针，M10 复习 M7 的中断。学过的点，每个月花 1 小时回看自己写的博客。

### 5. 岗位倒推：只学"面试会考 / 课题会用"的
学之前问自己一句话：

> **这个知识点，会在我的课题里用到，或者会在面试里被问到吗？**  
两个都不会 → 跳过。
>

这是砍掉 408 重学、砍掉编译原理/数据库的依据，也是你一年能学完的唯一原因。

### 6. 时间管理：番茄 + 固定时段 + 一次只做一件事
+ 番茄钟 25min 专注 + 5min 休息，一天 4–6 个番茄
+ **难的知识点放在每天精力最好的时段**（多数人是早上），碎片时间只看 `man` page 和源码
+ 写代码时关掉手机通知，避免上下文切换（切换一次成本约 15 分钟）

## 三、12 个月详细计划
> 每月 4 行：**目标 / 必做关卡 / 看什么视频 / 月底自查**。
>

### M1（2026.9）环境 + C 语法迁移
+ **目标**：Ubuntu 虚拟机或双系统装好，`gcc/gdb/make/valgrind/git` 全部跑通；认清 Java 和 C 的 6 个本质差异（无 GC / 无异常 / 数组不越界报错 / 无 String / 指针可运算 / 无包管理）。
+ **必做**：用 C 写一个能编译能跑的程序；用 `gdb` 走一遍；配好 `.vimrc`。
+ **视频**：翁恺《C语言程序设计》（浙大，B 站搜"翁恺"）+ 尚硅谷《Linux 入门》（搜"尚硅谷 Linux"）。
+ **自查**：能在命令行完成「编辑 → 编译 → 调试 → git 提交」闭环。

### M2（2026.10）C 内存与指针（最关键的月份）
+ **目标**：指针画得出内存图，不再"猜"；能手写 `memmove` 并讲清它和 `memcpy` 的区别（内存重叠）。
+ **必做**：关卡①②（手写库函数全家桶 + 手写内存池）。
+ **视频**：翁恺 C 语言后半段（指针/动态内存）+ 王道《数据结构》（为 M3 铺垫，B 站搜"王道 数据结构"）。
+ **自查**：`valgrind --leak-check=full` 能定位一个故意写出的内存泄漏；gdb 从 core dump 定位崩溃行号。

### M3（2026.11）位操作 + 编译链接 + 数据结构（C 实现）
+ **目标**：用 `gcc -S` 对比 `volatile` 加与不加的汇编差异，并解释阻止了哪步优化（**面试必考，必须讲到汇编级**）。
+ **必做**：关卡③④（`volatile` 汇编对比 + 用 C 手写动态数组/链表/哈希表）。
+ **视频**：王道《数据结构》+ 王卓《数据结构》（青岛大学，B 站搜"王卓 数据结构"，二选一即可）。
+ **自查**：能画出 `struct { char a; int b; short c; }` 的内存布局并说明为什么不是 7 字节；能手写多文件 Makefile。

### M4（2026.12）系统编程 I：文件 / 进程 / 线程
+ **目标**：手写简易 shell（支持管道 `|`、重定向 `>`、内建命令）。
+ **必做**：关卡⑤。
+ **视频**：黑马程序员《Linux 系统编程》（B 站搜"黑马 Linux 系统编程"）。
+ **自查**：能用 `strace` 看 shell 调了哪些系统调用；讲清 `fork` 的返回值两个分支。

### M5（2027.1）系统编程 II：网络
+ **目标**：TCP 服务器四版本（迭代 → 多进程 → 多线程 → `epoll`），并说清各自瓶颈。
+ **必做**：关卡⑥。
+ **视频**：黑马《Linux 网络编程》+ 湖科大教书匠《计算机网络微课堂》（B 站搜"湖科大教书匠"，选 TCP/IP 部分补理论）。
+ **自查**：能解释 `epoll` 相对 `select` 为什么是 O(1)（红黑树 + 就绪链表，**和你 Java 的 Netty Selector 对比着讲**）。

### M6（2027.2）第一个内核模块 + 字符设备驱动
+ **目标**：`hello.ko` 能 `insmod`/`rmmod`；字符设备驱动，用户态能 `read`/`write` 打通。
+ **必做**：关卡⑦⑧。
+ **视频**：韦东山《嵌入式 Linux 驱动开发基础》（B 站搜"韦东山"，从这里开始是嵌入式核心，换权威 UP 主）。
+ **自查**：能画出 `read()` 从用户态 → syscall → VFS → `file_operations` → 硬件寄存器的完整调用链。

### M7（2027.3）内核机制：中断 / 并发 / 内存
+ **目标**：能脱口而出中断上下半部分工、自旋锁 vs 互斥锁、`kmalloc` vs `vmalloc`。
+ **必做**：关卡⑨（带中断 + 并发控制的驱动）。
+ **视频**：韦东山《驱动》中断/并发部分 + 李治军《操作系统》（哈工大，B 站搜"李治军 操作系统"，只补进程调度和内存管理，理论快速过）。
+ **自查**：故意在中断里 `msleep()`，亲眼看到内核报 "BUG: scheduling while atomic"（**亲眼见过 > 背一百遍**）。

### M8（2027.4）platform 驱动 + 设备树（分水岭，驱动到此为止）
+ **目标**：独立完成一个完整驱动：platform + DTS + 中断 + 并发控制。**这是你驱动能力的上限，够用了——不再往下冲异构/PCIe/内核源码。**
+ **必做**：关卡⑩。
+ **视频**：韦东山《设备树 + platform 驱动》专项，或正点原子《Linux 驱动开发》（B 站搜"正点原子"，配合 i.MX6ULL 板子）。
+ **自查**：讲清 `compatible` 怎么匹配到驱动的；设备树节点如何转成 `platform_device`。

### M9（2027.5）硬件入门（点到为止）
+ **目标**：STM32 点灯 + 串口；逻辑分析仪抓一次 I2C 并解读 ACK。**能对话就行，不深挖硬件。**
+ **必做**：关卡⑪。
+ **视频**：江协科技《STM32 入门教程》（B 站搜"江协科技"，看前 1/3 即可）。
+ **自查**：拿着开发板原理图，指出某传感器连在哪条 I2C 总线；能解释"驱动看着没错但设备不响应"先抓波形查 ACK。

### M10（2027.6）系统 / 中间件实战（软工主场，重点月）
+ **目标**：写一个完整的 Linux 系统级项目——推荐「设备管理服务」或「多进程 IPC 框架」，把**系统编程 + 并发 + 网络 + 基础驱动**四合一。这是你面试的压舱石。
+ **必做**：关卡⑫（系统实战）。
+ **视频**：黑马《Linux 项目实战》或韦东山《Linux 应用开发项目课》。
+ **自查**：项目能用 `strace`/`perf` 分析性能；能讲清线程池、`epoll`、锁的取舍。
+ **降级**：BSP 全链路（U-Boot + 裁剪 + Buildroot）降为**选做了解**，面试问到能讲清启动流程即可，不实操。

### M11（2027.7）课题项目 / 实习变现
+ **目标**：把课题翻译成简历项目（四段式：背景 / 我的工作 / 技术难点 / 量化结果）；投第一段实习。
+ **必做**：按 [嵌入式Linux研究生规划.md](嵌入式Linux研究生规划.md) 第六章方法改造课题（**定位往②内核/系统优化靠**）；写一份技术文档 + 3 篇博客。
+ **视频**：无固定视频，转为看牛客面经（B 站搜"嵌入式 面经"）。
+ **自查**：简历上有一个项目能讲 10 分钟不停，包含一个"最难调的 bug"真故事。

### M12（2027.8）八股 + 简历定稿
+ **目标**：简历初稿完成；8 个必问内核题能脱口而出；LeetCode 累计 150+ 题。
+ **必做**：刷牛客嵌入式八股（241 道真题）；简历找师兄/导师改一轮。
+ **视频**：代码随想录（B 站搜"代码随想录"，卡尔）补算法题思路。
+ **自查**：8 个内核题（见下）每题 2 分钟内讲清，一个都答不出就别投简历。

**8 个必问内核题**：① `kmalloc` vs `vmalloc` ② 中断上下半部分工 ③ 为什么中断上下文不能睡眠 ④ 自旋锁为什么不能睡眠 ⑤ `ioremap` 做了什么 ⑥ DMA 与 Cache 一致性 ⑦ RCU 为什么快 ⑧ `read()` 到驱动的完整链路。

## 六、书籍（极简，只留必读）
> **原则：不读书，动手做。** 书是"查的"，不是"通读的"。除 FreeRTOS 源码外，没有需要通读的书。
>

| 优先级 | 书 | 什么时候 |
| --- | --- | --- |
| 🔴 | 《C 和指针》+《C 陷阱与缺陷》 | M1–M3，当字典查 |
| 🔴 | 《Linux/UNIX 系统编程手册》(TLPI) 或 APUE | M4–M5，当字典查 |
| 🔴 | 《Linux 内核设计与实现》(LKD) | M6–M7 选读 |
| 🟡 | 韦东山 / 正点原子《驱动开发手册》 | M8–M10 |
| 🟢 | FreeRTOS 源码（约 1 万行） | M7 后，唯一值得通读的 |


**权威手册（不是书，是查的）**：Linux `man` pages（`man 2 read`、`man 3 malloc`）→ 最权威；内核源码 `Documentation/` → 比大部分书准确；C99/C11 标准 → 不确定行为查标准**别查博客**；[LWN.net](https://lwn.net/) → 内核机制"为什么这么设计"。

## 7、每周节奏 + 三条铁律
| 时段 | 做什么 | 时长 |
| --- | --- | --- |
| 工作日早/晚 | 关卡推进（**写代码，不是看视频**） | 1.5–2 h/天 |
| 工作日碎片 | `man` page、内核源码、技术博客 | 0.5 h |
| 周末一天 | 整块攻坚，一个知识点啃完 | 6–8 h |
| 周末另一天 | 课题 + LeetCode + 写博客复盘 | 4 h |


**三条铁律：**

1. **代码量 > 视频时长。** 看 10 小时视频不如写 2 小时代码。
2. **一个月一个关卡。** 完不成说明目标太大，拆小，但别拖。
3. **每关一篇博客。** 不写博客的关卡等于没做——面试时你讲不出来。

> ⚠️ **最大的风险不是学不会，是"看视频看了一年"。** Java 转 C 的人尤其容易这样——C 的坑必须踩过才知道，看是看不出来的。
>

## 八、明确不学的
| 科目 | 决定 | 理由 |
| --- | --- | --- |
| 数据结构理论 / 操作系统教材 / 计网教材 | ❌ 不重学 | 408 已学，**只补 C 实现 / 直接读内核源码 / 抓包写代码** |
| MIPS 汇编 / 运算器 / 微程序 | ❌ 跳过 | 嵌入式用 ARM |
| 编译原理 / 数据库 / SQL | ❌ 跳过 | 驱动岗不考，嵌入式基本不用 |
| 设计模式 | 🟡 10 分钟过名词 | 偶尔问单例、工厂 |
| 图形学 | ❌ 跳过 | 除非做 GPU 驱动 |
| AI 理论 / 炼丹 | 🟡 看定位 | 只有选"边缘 AI"才需要，且只需模型部署 |
| 算法竞赛 | ❌ 不碰 | LeetCode 150–250 题够用 |
| xv6 完整实验 | 🟡 可选 | 收益大但耗时，排在关卡⑩之后 |
| **异构多核 / PCIe / GPU 驱动** | ❌ 不学 | 难度极高，双非硕士红利岗不考，别拿劣势硬刚 |
| **BSP 深度裁剪 / Yocto** | 🟡 了解即可 | 面试能讲流程就行，不实操 |


**判断法则（再强调一遍）**：学之前问——**课题用得到吗？面试会问吗？** 都不会 → 跳过。
