

## 一、适合你的学习方向
  你已经会一些编程语言和基础算法，因此不需要从头学习编程语法。接下来应重点补充：

  计算机基础  
  → 命令行与开发工具  
  → Git 版本控制  
  → 软件工程  
  → 网络与 API  
  → 数据库  
  → 测试与调试  
  → 项目部署

  建议主语言使用 Python。它适合文本处理、自动化、数据整理和开发小型 Web 应用。

  ———

# 四、第一天可以开始的操作
  在 PowerShell 中执行：

  New-Item -ItemType Directory "$ HOME\dev-study"
  Set-Location " $HOME\dev-study"

  python --version  
  git --version

  New-Item -ItemType Directory "hello-project"  
  Set-Location "hello-project"

  python -m venv .venv  
  ..venv\Scripts\Activate.ps1

  如果需要安装 Python 包，可以使用国内镜像：

  python -m pip install -i [https://pypi.tuna.tsinghua.edu.cn/simple](https://pypi.tuna.tsinghua.edu.cn/simple) "fastapi[standard]"

# 五、每天的学习方法
  每学习一个知识点，完成以下步骤：

  阅读 20 分钟文档  
  ↓  
  照着例子运行  
  ↓  
  主动修改 3 个地方  
  ↓  
  关闭资料后重新写一遍  
  ↓  
  提交到 Git

  每天建议安排：

   时间       内容  
  ━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━  
   20 分钟    阅读文档或观看课程  
  ─────────  ────────────────────  
   40 分钟    跟着示例编程  
  ─────────  ────────────────────  
   30 分钟    修改和扩展代码  
  ─────────  ────────────────────  
   10 分钟    总结并提交 Git

# 六、如何使用 AI 辅助学习
  不要只让 AI 直接写完整代码，而应该让它解释问题和引导你排查。

## 遇到报错时
  我现在是计算机初学者。请解释这条报错每一部分的含义，  
  再告诉我应该按照什么顺序排查。  
  不要直接重写全部代码。

## 检查代码时
  请检查我的程序：

1. 功能是否正确
2. 哪些地方可能报错
3. 哪些地方难以维护
4. 应该增加哪些测试

  请先指出问题，再给出修改建议。

## 学习新概念时
  请用初学者能理解的方式解释 HTTP 请求和响应。  
  先用生活中的例子说明，再用一个简单的 Python 示例说明。  
  最后给我 3 道练习题，不要立即给答案。

  ———
